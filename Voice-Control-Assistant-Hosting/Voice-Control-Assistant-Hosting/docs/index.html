Project highlights

🎤 Voice commands

Control supported desktop actions through spoken commands. Offline speech recognition can be configured with a Vosk model.

🧠 Local AI option

Connect an Ollama model running on your own computer for local question answering and code-generation assistance.

🖥️ Desktop productivity

A collection of desktop utilities and automation workflows, depending on the installed dependencies and permissions.

📄 Reading assistance

PDF text extraction and optional screen OCR can be configured with the required local tools.

How it works

1. Desktop application

Runs locally on Windows and accesses your microphone and desktop with your permission.

2. Optional local services

Vosk and Ollama run on your PC. Model files are installed separately and are not included in this website.

3. Project website

This static page is published using GitHub Pages. It documents the project; it does not run the desktop assistant.

Getting started

Use the repository README as the source of truth for the latest installation instructions and dependency versions.

git clone https://github.com/shivamgupta4469/Voice-Control-Assistant.git
cd Voice-Control-Assistant
python -m pip install -r requirements.txt

For offline speech and local AI, install the required Vosk model and Ollama model as described in the repository setup guide. Some features may require internet access or additional Windows software.
